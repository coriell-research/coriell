# Differential expression results from GSE161650

A subset of differential expression results comp THZ1 (n=3) vs DMSO
(n=3) samples after analysis with edgeR. See Details for citation.

## Usage

``` r
GSE161650_de
```

## Format

A data frame with 11,002 rows and 6 columns:

- feature_id:

  Gene Symbol

- logFC:

  log2 fold-change THZ1 vs DMSO

- unshrunk.logFC:

  unshrunk log2 fold-change THZ1 vs DMSO

- logCPM:

  Average logCPM across all samples

- PValue:

  Uncorrected PValue

- FDR:

  FDR Adjusted PValue
